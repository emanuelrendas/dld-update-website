chore: API docs and JSON content-type headers (audit fixes)

Adds operational docs for the Dubai Pulse dataset and basic API notes, and ensures both serverless endpoints explicitly set Content-Type: application/json for clearer local testing.

Files changed
- README_DLD.md (new) — how to request Dubai Pulse DLD dataset and Vercel env var setup
- README_API.md (new) — quick local dev checklist and 90‑second validation
- api/dld.js (minor) — res.setHeader('Content-Type','application/json')
- api/fx.js  (minor) — res.setHeader('Content-Type','application/json')

Why
- Makes endpoints easier to test locally and prevents subtle tooling errors that assume a JSON content-type.
- Documents how to get Dubai Pulse credentials and how to run the 90‑second validation locally, so reviewers can reproduce behaviour without guessing.

Validation checklist (90‑second workflow for reviewers / Claude)
1) Start local dev server
   - In the repo root:
     - vercel dev
   - Default dev URL: http://localhost:3000

2) Smoke the API endpoints (confirm headers and JSON shape)
   - curl -i http://localhost:3000/api/fx
     - Expect: Content-Type: application/json and JSON keys: ok, live, source, date, rates
   - curl -i http://localhost:3000/api/dld
     - Expect when no creds: { "configured": false, "message": "…" }
     - With DUBAI_PULSE_KEY and DUBAI_PULSE_SECRET set locally: configured:true and aggregated payload (totals, areas)

3) Force fx fallback (optional)
   - Temporarily block api.frankfurter.app (hosts or firewall) and re-run /api/fx — expect live:false and FALLBACK rates.

4) Quick site sanity: seven routes + no console errors
   - Visit: /  /about  /advisory  /intelligence  /addresses  /instruments  /contact
   - Check: no JS console errors, no failed requests, no horizontal overflow, one H1 per page, DLD panel fallback when configured:false.

5) Response header check (explicit)
   - curl -I http://localhost:3000/api/fx  → look for Content-Type: application/json
   - curl -I http://localhost:3000/api/dld → look for Content-Type: application/json

6) Safety checks
   - Confirm no secrets committed:
     - git diff --name-only origin/main...HEAD
     - git grep -n "DUBAI_PULSE_KEY\|DUBAI_PULSE_SECRET"
   - Env vars should be set in Vercel only.
